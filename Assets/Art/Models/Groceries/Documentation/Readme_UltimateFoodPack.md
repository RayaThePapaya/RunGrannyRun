# 🍔 Ultimate Food Pack (103 Low-Poly Models)

Welcome to the **Ultimate Food Pack** by AZ Studios!
This package contains 103 high-quality, lightweight, low-poly 3D food items perfectly optimized for mobile, desktop, VR, and console games.

---

## 📁 Package Structure

* **`FBX/`**: Contains 103 raw 3D mesh FBX files.
* **`Prefabs/`**: Contains 103 pre-configured game object prefabs with zeroed transforms and MeshColliders.
* **`Scenes/`**: `UltimateFoodPack_Showcase.unity` — A pre-arranged showcase scene organizing all 103 food items in grid rows.
* **`Documentation/`**: `Readme_UltimateFoodPack.md` — Package instructions and guidelines.

---

## 🎨 Render Pipeline Compatibility

Compatible out-of-the-box with all Unity render pipelines:
* **URP (Universal Render Pipeline)**
* **Built-In Render Pipeline**
* **HDRP (High Definition Render Pipeline)**

---

## 🍕 Included Models List (103 Items)

Includes Burgers, Pizzas, Donuts, Ice Creams, Fruits, Vegetables, Meat, Cooking Pots, Utensils, Beverages, Sauces, and Snacks!
